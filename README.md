# 🧠 Ficha de Treino

Aplicação web desenvolvida para facilitar o acompanhamento de treinos de musculação de forma prática e acessível via dispositivo mobile.

O projeto foi pensado para uso real no dia a dia, com foco em **simplicidade, usabilidade e organização de treinos**.

---

## 🔗 Acesse o projeto

👉 https://ficha-de-treino.vercel.app

---

## 🚀 Funcionalidades

* Visualização organizada da ficha de treino
* Exibição de exercícios com apoio visual (GIFs demonstrativos)
* Modal com detalhes e execução correta dos exercícios
* Interface otimizada para uso em dispositivos móveis
* Estrutura simples e direta, focada na experiência do usuário

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)
* Deploy: Vercel

---

## 📱 Decisões de desenvolvimento

* Interface mobile-first para uso direto na academia
* Estrutura leve, sem dependência de frameworks
* Foco em carregamento rápido e navegação simples
* Organização dos conteúdos por tipo de treino

---

## 📁 Estrutura do projeto

```
fichaDeTreino/
├── assets/        # Imagens e GIFs dos exercícios
├── html/          # Páginas organizadas por treino

```

## 🔧 Como executar localmente

```bash
git clone https://github.com/brunodomingues98/fichaDeTreino.git
cd fichaDeTreino
```

Abra o arquivo `index.html` no navegador.
